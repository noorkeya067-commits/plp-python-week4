# Week 4 Assignment: Hands-On Lab — Grades, Eligibility & Smart Decisions

## Files

- `grade_classifier.py` — Classifies a score from 0 to 100 into a letter grade.
- `eligibility_checker.py` — Checks whether a person is eligible to join a local coding club.
- `atm_menu.py` — Provides a simple ATM menu for checking balance, withdrawing, and depositing money.
- `screenshots/` — Contains screenshots showing the programs running successfully.

## Reflection

`elif` is better than several separate `if` statements when you are checking multiple conditions where only one result should be selected. It makes the code easier to read and ensures that once one condition is true, the remaining conditions are not checked.
